# FP9 Host

Professional Discord Bot Hosting Platform

## Features

- Discord OAuth Login
- ZIP Upload with Auto Language Detection
- .env Variable Editor
- Bot Management Dashboard
- Real-time Logs
- Resource Monitoring
- Dark Mode
- Arabic/English Support

## Getting Started

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000)

## Deploy to Netlify

1. Push to GitHub
2. Connect repository to Netlify
3. Build command: `npm run build`
4. Publish directory: `out`

## Discord OAuth Setup

To enable Discord login, create a Discord Application at https://discord.com/developers/applications and update the OAuth URL in `components/Navbar.tsx`.
